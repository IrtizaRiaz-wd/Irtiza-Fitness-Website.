# Irtiza Fitness — Website

Static fitness landing page ready for deployment.

## Files

- `index.html` — Main page
- `style.css` — Styles (premium navy + teal theme)
- `script.js` — Interactions (nav, form, counters, AOS)

## Deploy

Upload the contents of this folder to any static host:

- **Netlify / Vercel / Cloudflare Pages** — drag & drop or connect Git
- **GitHub Pages** — push to a repo and enable Pages
- **Any web host** — upload via FTP/cPanel

No build step required. Open `index.html` locally to preview.
